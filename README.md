# 🌍 CO₂ Emission Analysis & Forecasting

## 📌 Overview

This project focuses on analyzing historical CO₂ emissions and forecasting future trends using machine learning techniques. It aims to identify high-emission regions and provide data-driven insights for mitigation.

## ⚙️ Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib

## 📊 Key Features

* Trend analysis of global CO₂ emissions
* Identification of top emitting countries
* Predictive modeling using regression techniques
* Future emission forecasting (2025–2040)

## 🤖 Models Used

* Linear Regression
* Random Forest Regressor

## 📈 Outcome

The model provides reliable emission forecasts and highlights critical regions requiring intervention, supporting sustainable decision-making.

## 🚀 Execution

```bash
python co2_project.py
```
